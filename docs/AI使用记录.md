# AI 使用记录

## 使用的 AI 工具

- **Cursor**：AI 编程编辑器，使用其内置的大模型完成对话、方案编写、编码和文档撰写。

## AI 在本次作业中的具体作用

我以产品经理的角色使用 AI：**我负责产品方向、关键决策和质量把关，AI 负责方案细化和执行。**

| 环节 | AI 的作用 | 我的决策与把关 |
| --- | --- | --- |
| 方向构思 | 根据笔试题目和小影的业务，提出 4 个候选方向：小商家商品短视频生成、爆款结构拆解复刻、vlog 素材自动成片、口播智能粗剪 | 选定「爆款结构拆解复刻」 |
| 方案设计 | 编写实现方案，包括产品流程、页面交互、数据结构、模型调用和降级策略、测试计划 | 决定「有 Key 时调用真实模型，没有或失败时退回演示数据」；没有采纳 AI 推荐的「代码 + 演示视频」，选择只交代码，并要求不配置 Key 也能完整体验 |
| 方案审查 | 按我的要求连续 3 轮审查方案，删掉多余功能（独立首页、平台选择、概念按钮），增加可验证的原创性检查，修正 6 处会导致 bug 的设计，补齐实现细节 | 规定审查角度：合理性、是否过度设计、是否足够细致、能否避免实现偏差；方案确认后才开始写代码 |
| 开发实现 | 编写 Demo 代码（Next.js + TypeScript）和 74 个单元测试，通过 lint、类型检查和生产构建 | 要求实现与方案一致，偏差需同步回方案 |
| 测试验证 | 在浏览器中走查完整流程和各项交互，用错误的 Key 验证失败降级；实现完成后逐节核对方案，补测了 2 项此前未在页面上验证的功能 | 要求逐条核对方案的完成情况 |
| 文档撰写 | 撰写产品说明文档和 README 的初稿，截取 Demo 截图 | 确定第 5 题写剪映；审阅文档，调整表述和重点 |
